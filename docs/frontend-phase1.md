# 一期前端对接说明

## 技术栈

- Vue3
- TypeScript
- Vite
- Lucide Icons
- ECharts

## 已对接模块

- M1 用户、课程、章节、成员
- M2 资料上传、解析、脚本、音频、向量状态
- M3 课堂播放、字幕、页码、学习进度、课堂提问
- M4 RAG 问答、来源引用、历史、收藏、评价
- M5 文本/图片题目、OCR 确认、分级辅导、易错点、相似题
- M6 知识点难度、测验练习、错题、薄弱点、学习计划、学习记录
- M7 教学分析图表、时间筛选、AI 建议
- M8 用户、课程、资料、模型、服务、系统参数、监控、日志、备份

## 管理端新增入口

- 模型用途包含 `embedding`
- 服务类型包含 `email`
- 日志支持用户、动作、对象、级别、来源、时间筛选
- 备份支持创建、恢复、删除

## 验证

```bash
cd frontend
npm run build
```

已通过构建验证。
