# 一期前端对接说明

## 技术栈

- Vue3
- TypeScript
- Vite
- Vue Router
- Pinia
- Lucide Icons
- ECharts

## 已对接模块

- M1 用户、登录、注册、找回密码、个人资料、课程、章节、成员、退课
- M2 资料上传、分类、章节绑定、解析状态、脚本审核、音频预览、向量状态、资料检索
- M3 课堂列表、PPT 翻页、音频播放、暂停、调速、字幕、恢复学习、自动进度、课堂提问
- M4 RAG 问答、多轮追问、来源引用、超范围提示、历史搜索、收藏、评价
- M5 文本题、图片题、OCR 确认、知识点、三级辅导、易错点、相似题、历史
- M6 知识点难度、课程测验、章节练习、自动判分、AI 反馈、错题本、错题重练、薄弱点、学习计划、打卡、学习记录
- M7 高频问题、薄弱点、低活跃、成绩分布、完成率、AI 建议、雷达图、时间筛选
- M8 用户、课程、资料、模型、服务、系统参数、监控、日志、备份

## 管理端新增入口

- 管理员端已按 `admin.md` 独立重构为固定顶部栏、可折叠侧栏、面包屑和内容区
- 总览仪表盘包含统计卡、趋势图、AI 调用分布、服务状态、最近操作、课程排行、最近注册、待处理事项
- 用户管理包含统计、筛选、批量操作、详情抽屉、创建管理员弹窗
- 课程管理包含统计、筛选、表格/卡片视图、详情抽屉、接管、下架
- 资料审核包含统计、筛选、预览、下载、批量删除
- 模型用途包含 `embedding`
- AI 模型配置拆分为大语言模型、Embedding、调用统计
- 服务类型包含 `email`
- 阿里云服务配置按 OSS、OCR、TTS、邮件独立卡片展示
- 系统参数按文件上传、AI 行为、课堂音频、测验、界面公告、备份分类管理
- 系统监控支持服务总览、趋势图和 30 秒自动刷新
- 日志支持用户、动作、对象、级别、来源、时间筛选
- 日志管理支持登录、操作、错误三类 Tab，错误日志可标记处理
- 备份支持摘要、创建、校验、下载、恢复、删除和自动策略配置
- 监控展示数据库、缓存、异步队列、Celery 状态
- 资料审核展示按类型、分类、教师、时间统计
- 服务配置展示 OSS / 本地存储状态
- 模型配置展示用途说明，支持编辑、测试、删除
- 服务配置展示用途和必填字段，支持编辑、测试、删除
- OSS、OCR、TTS、邮件各自独立配置区域
- 系统参数展示参数含义
